# Портфолио — контекст проекта

Личный сайт-портфолио (визитка) creative-разработчика. Общение с пользователем — на русском.

## Стек (решено)

- **Astro 7** — фреймворк, статическая генерация, острова.
- **React** (через `@astrojs/react`) — только для острова с 3D-сценой.
- **Three.js + @react-three/fiber (R3F)** — WebGL-сцена на первом экране.
- **GSAP** (+ ScrollTrigger) — кинетическая типографика и скролл-анимации.
- **View Transitions** — через `<ClientRouter />` из `astro:transitions` и атрибут `transition:name`.
- **Content Collections** — кейсы в Markdown. В Astro 7: `defineCollection` из `astro:content`, `glob` из `astro/loaders`, `z` из `astro/zod` (импорт `z` из `astro:content` устарел).

Окружение пользователя: Windows, PowerShell, Node 24, проект в `D:\lport\portfolio`. Dev-сервер: `npm run dev` → http://localhost:4321.

## Дизайн: «тёмный минимализм + яркий шейдер»

Утверждён набросок. Ключевые параметры:

- Цвета: фон `#0b0b0d`, текст `#edebe6`, приглушённый `#8d8c92`, мягкий `#b4b3b8`, линии `rgba(237,235,230,.14)`, акцент лайм `#c6f432`, свечение фиолетовое `#5b3df5`.
- Шрифты (Google Fonts): **Unbounded** 300/500/700 — заголовки; **Manrope** 400/500/600 — текст; **JetBrains Mono** 400/500 — мелкие подписи капсом (класс `.mono`).
- Все токены — CSS-переменные в `src/styles/global.css` (`--bg`, `--fg`, `--muted`, `--soft`, `--line`, `--accent`, `--glow`, `--font-display`, `--font-body`, `--font-mono`, `--gutter: clamp(20px, 4vw, 56px)`, `--ease-out: cubic-bezier(.16,1,.3,1)`).

Структура главной (текущая, отличается от исходного наброска):
1. **Hero** (200svh, контент закреплён sticky): WebGL-шейдер на весь фон; сверху заголовок «Сайт, который хочется трогать» в одну строку капсом, подогнан под ширину экрана (`fitLogo`), «трогать» — акцент; реакции букв на курсор нет (убрана по просьбе). Огонёк с дымкой в шейдере пробовали — пользователь отказался. Мышь шейдер слушает на `window` (на `.hero` события перехватывает блок работ). Внизу слева — местное время и город, справа — «Открыт к проектам» с пульсирующей точкой. Других подписей и меню на первом экране нет (пользователь их убрал). При скролле верх уезжает, появляется фиксированная шапка `Header`.
2. **Избранные работы** (`#works`): стартует миниатюрой — вся сцена уменьшена `scale(var(--thumb))` от нижнего края и выезжает поверх hero; при скролле разворачивается на весь экран. Дальше закреплённая 3D-карусель плоскостей со snap, слева детали проекта и счётчик `01/04`, справа список. Первая карточка — приглашение «Вы» / «Клиент №1» (`you.md`, `href: /#contact`, без страницы кейса). Вариант с чемоданчиком пробовали — пользователь отказался.
3. **Бегущая строка** стека: Unbounded 700, контурный текст, разделители ✳ акцентом, ускоряется от скорости скролла. Стоит после блока работ: если поставить её между hero и Works, она сдвигает закреплённый блок работ вниз и сама прячется под ним.
4. **Обо мне** (`#about`): `site.intro` + навыки-«пилюли».
5. **Контакты** (`#contact`): «Давайте сделаем что-то живое» — фраза мигает как старая лампа (`buzz`), «живое» на плашке щёлкающе меняет цвет плашки и текста (`lamp`, `step-end`); email крупно, нижняя строка: копирайт, соцсети, город.

## Шейдер первого экрана

Готовый GLSL — в `reference/hero.frag`. Это фрагментный шейдер на полноэкранной плоскости: fbm-шум с доменным искажением, «топографические» изолинии акцентного цвета, фиолетовое свечение, виньетка, лёгкое зерно. Линии стягиваются к курсору и ярче подсвечиваются рядом с ним.

Uniforms: `uRes` (px), `uTime`, `uMouse` (px, ось Y снизу), `uHover` (0..1), `uAccent`, `uGlow` (vec3), `uIntensity`.

Поведение мыши из наброска (перенести в R3F `useFrame`):
- позиция мыши сглаживается lerp с коэффициентом ~0.07 за кадр;
- `uHover` плавно идёт к 1 при наведении и к 0.35 без него (lerp 0.05);
- когда курсора нет — точка притяжения плавает сама: x = 0.6 + 0.18·sin(t·0.31), y = 0.42 + 0.16·sin(t·0.23 + 1.3) (доли ширины/высоты);
- dpr ограничить `[1, 1.5]`;
- `prefers-reduced-motion` — время заморожено.

В R3F: `<Canvas>` с ортографической настройкой или просто плоскость `planeGeometry args={[2,2]}` с вершинным шейдером `gl_Position = vec4(position.xy, 0., 1.)`. Остров подключать через `client:only="react"`. Цвета брать из тех же значений, что и CSS-переменные.

## Как работать с пользователем

Пользователь учится: объясняй кратко, что и зачем делаешь на каждом шаге, особенно новые концепции (острова, шейдеры, uniforms, GSAP-таймлайны, View Transitions). После каждого крупного шага — проверка в браузере (`npm run dev`).
